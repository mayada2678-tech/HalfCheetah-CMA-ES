# HalfCheetah-v5 Optimization using CMA-ES

An evolutionary reinforcement learning project optimizing a continuous control policy for the Gymnasium/MuJoCo `HalfCheetah-v5` environment using the **CMA-ES (Covariance Matrix Adaptation Evolution Strategy)** algorithm.

## 🚀 Features
- **Evolutionary Policy Optimization:** Neural network weights optimized via CMA-ES.
- **Interactive GUI:** Built-in dashboard to configure parameters, track training progress, and visualize policy evaluations.
- **Model Checkpointing:** Save and load best-performing policy weights.
